Like many others, I was captivated by *Legend of Mana* growing up. Its art, music, atmosphere, and unusual approach to storytelling made it feel different from almost anything else I had played.

Some of my favorite memories are of sitting in front of the TV on a Saturday morning with a friend, playing through the game together in two-player co-op. There was always another place to explore, another character to meet, or another strange little story waiting somewhere in the world. It was one of those games that simply felt special. I loved finding and discovering secrets that came as a surprise on each playthrough.

When I was younger, I remember thinking that I wanted to make a game like this someday. I wanted to create that same feeling of adventure and discovery for somebody else—to build worlds, stories, and experiences that people might remember years later.

As I got older, that turned into a deeper appreciation for the people who actually make games like these. I especially admire developers who are willing to experiment, take risks, and make something that doesn't quite follow the usual RPG formula.

## Why decompile it?

Part of the reason I started this project is simply because I want to learn.

Decompiling a game means working backward from the compiled program and reconstructing source code that represents how it was originally built. In the case of a matching decompilation, the goal goes even further: the reconstructed source should compile back into the same machine code as the original game.

That process forces you to understand a game at a very different level. You begin learning about its programming, data structures, build tools, compiler behavior, file formats, and all of the small implementation decisions that normally remain invisible to the player.

For me, that makes this an educational project—but education isn't the only reason I'm doing it.

I also want to help preserve some of the development history behind the game.

The finished game itself has been preserved, and it has even received a modern remaster. But there is a difference between preserving a game and preserving an understanding of **how that game was constructed**.

The original source code and many of the technical decisions behind older games are often unavailable to the public. By reconstructing as much of that information as possible, we can create a record that may otherwise never exist.

I don't see this project simply as a way to eventually port the game to other platforms. To me, it is much more of a labor of love: an attempt to understand a game that meant a lot to me, while documenting what I learn so that the information is available to others in the future.

## Where does it go from here?

I don't know whether I will be able to reach a 100% matching decompilation by myself. It's a large project, and I'm working on it in my free time. 
But I am having fun figuring out secrets just in a different way compared to when I was playing the game as a kid. 
I hope that other people will appreciate this project too.
