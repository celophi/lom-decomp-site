The homepage now has one job: explain what **lom-decomp** is.

This blog is where everything else can go. Project milestones, reverse-engineering discoveries, compiler oddities, retrospectives, and longer explanations can be published here without turning the homepage into documentation.

## What to expect

As the project progresses, posts can cover topics such as matching difficult functions, reconstructing old PlayStation build behavior, discoveries about the game's systems, and major project milestones.

Posts are ordinary Markdown files, so adding a new entry does not require editing the site layout.
